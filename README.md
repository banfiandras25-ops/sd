# Állatblog webalkalmazás

Egyszerű webes alkalmazás állatokkal kapcsolatos blogbejegyzések közzétételéhez és olvasásához.
Alapvető HTML/CSS frontenddel, PHP háttérprogrammal és MySQL adatbázissal építve.

## Jellemzők
- Felhasználó regisztráció és bejelentkezés és kijelentkezés és feltöltés
- A munkamenet fennmaradása cookie-k használatával
- Állat témájú blogbejegyzések
- Csak adminisztrátori felhasználókezelő oldal
- Egyszerű és könnyű architektúra
- MySQL adatbázis integráció

## Tech Stack
### Frontend
- HTML5
- CSS3
### Backend
- PHP
### Adatbázis
- MySQL
